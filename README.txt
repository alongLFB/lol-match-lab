LoL 对局实验室 (LoL Match Lab)
=====================================

免安装 · 零依赖 · 纯本地运行 · 游戏即连即用

双击「LoL对局实验室.exe」即可使用。
无需安装 Node.js、无需运行命令行、无需安装额外依赖，自带独立运行环境。

-------------------------------------
【快速使用指南】
-------------------------------------
1. 启动游戏：
   先打开英雄联盟客户端并登录游戏大厅（国服或外服均支持）。

2. 运行本工具：
   双击「LoL对局实验室.exe」，程序将直接弹出独立的 Windows 桌面客户端软件窗口（无需打开外部浏览器）。
   自带独立运行环境，告别浏览器标签页，像正规 Windows 软件一样直接在窗口中操作！

3. 查看对局与分路：
   - 「近期战绩」：自动加载当前账号最近对局，点击可一键导入本地库。
   - 「对局详情」：自研三维时空聚类算法，100% 还原真实对线分路（精准识别非常规对位）。
   - 「实时观战」：自定义内战观战或游戏进行时，后台全自动每分钟快照，退出观战不丢数据。

4. AI 智能复盘：
   - 在「设置」中填入您的 OpenAI / DeepSeek / OneAPI 密钥与模型。
   - 点击对局详情页的「生成 AI 复盘」，自动生成职责化深度点评与幽默锐评。

5. 一键生成战报海报：
   - 点击「分享战报长图」，纯前端一键渲染高清精美长图。
   - 点击「复制到剪贴板」，直接去微信、QQ 或钉钉群按 Ctrl+V 发送复盘！

6. 内战多维看板：
   - 对局详情页点击「加入内战」，自动聚合统计红蓝胜率、选手战力榜、MVP/SVP 次数。

-------------------------------------
【数据与备份说明】
-------------------------------------
- 所有数据（导入的比赛记录、内战战绩、AI 评价、用户设置）均保存在本程序同级目录的「data」文件夹中。
- 100% 绿色便携：移动整个文件夹到其它电脑或 U 盘，所有历史战绩完整保留。
- 备份方法：直接复制「data」文件夹即可。

-------------------------------------
【常见问题】
-------------------------------------
1. 杀毒软件提示或拦截？
   本程序采用 PyInstaller + Node.js 独立打包为单文件便携软件，未购买商业数字签名。个别杀毒软件可能会误报，请选择「信任/允许运行」即可。
   本项目完全开源，所有代码均在 GitHub 上公开可查。

2. 提示“等待英雄联盟客户端启动”？
   请确保游戏客户端已启动并进入大厅。如果使用的是外服或特殊权限启动的游戏，可在本软件「设置」页面手动输入安装路径或端口密钥。

3. 端口 5179 被占用？
   如果重复双击打开，程序会自动切换到已在运行的浏览器页面，不会产生端口冲突。
   如需强制重启后台，可在桌面控制台界面点击「重启服务」。

4. 如何彻底退出？
   直接关闭客户端主窗口，后台服务将自动安全终止。
